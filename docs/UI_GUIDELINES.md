# R3 Desktop UI Guidelines

R3 uses a dense, keyboard-friendly ERP shell: top navigation, working context (Firma/Şube/Depo), tab workspace, and status bar. Lists use the same toolbar order: Yeni (F2), Düzenle (F3), Yenile (F5), Aktif/Pasif, Ara. Double-click opens the selected record; forms use Kaydet (Ctrl+S) and İptal (Esc).

Use readable neutral surfaces, restrained blue accents, compact rows, visible empty/loading states, and no decorative gradients or blocking success dialogs. Reuse the workspace tab instead of opening duplicate windows.
